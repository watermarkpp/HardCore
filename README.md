# 玛法离线原型

## 项目定位

私人离线刷装游戏，以传奇1.76为可追溯、不可被扩展内容污染的基准层，在其上构建可长期增加装备、属性、套装、Boss、地图、任务、职业玩法与不同美术风格的扩展层。所有系统优先满足数据可追溯、玩法可扩展、资源可替换、系统可测试和内容可批量生产。最高原则详见 `Total_Project_Plan_Task_Structure.md`。

## 资源目录约定

- `assets/art`：仅保存Godot运行时直接引用的最终图集，会进入资源导入和发布包。
- `dev_art_sources`：保存绿幕原图和透明关键源图，目录内有`.gdignore`，不会被Godot扫描或打包。
- `tools/build_directional_anchor_atlas.py`：从开发源图重建战士图集。
- `tools/build_bich_monster_atlases.py`：从开发源图重建比奇怪物与骷髅精灵Boss图集。
- `tools/build_bich_environment_assets.py`：从比奇环境母版重建8格地砖图集，并本地生成树木、岩石与城墙物件图集。
- `tools/build_orc_tomb_client_assets.py`：从客户端D001/D002/D003与Tiles/Objects库重建8格地砖、8格洞壁、火光、阻挡掩码和来源清单；旧入口会转发到此工具。
- `scripts/environment_catalog.gd`：五类环境主题及地图的地砖、路线、物件、碰撞、灯光数据目录。
- `scripts/environment_validator.gd`：自动校验图集尺寸、资源引用、碰撞/灯光数量、门点安全与路线接通。
- 新增源图后必须放入`dev_art_sources`；只有最终运行时图集可以写入`assets/art`。

Godot 4.7 标准版 / GDScript / Compatibility 渲染器。

Android M7里程碑包：`outputs/legend176/MafaOffline_M7_2_milestone.apk`（arm64、API 24–36、版本24 / 1.13-m7.2、Sensor Landscape）。项目内`tools/verify_android_build.ps1`可校验签名、包名、版本、架构与方向。
