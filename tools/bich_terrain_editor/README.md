# 比奇省地形设计器

推荐双击 `Launch_Map_Editor.cmd` 使用；它会启动本地服务并打开浏览器，不连接互联网。

编辑范围严格对应比奇省 700×700 原始地图坐标。现在可以同时设计地形、碰撞、NPC、怪物刷新点、地图出入口和全部哥特营地装饰物。完成后导出：

v1.0已经升级为通用编辑器，可新建32至1000格的任意矩形地图，并使用十个标准图层。

- `bich_region_design.json`：包含地形和所有对象，供项目运行时转换和应用；
- `bich_region_preview.png`：包含实体标记的整体预览图。

禁行区使用独立标记保存，不会与地面外观混在一起。这样可以确保“看起来能走的地方确实能走”。
