# SAVE-MULTI-1：多角色与启动选择系统

> 完成日期：2026-07-04  
> 任务状态：100%

## 完成效果

- 应用启动后先进入角色选择画面，不再直接载入游戏世界。
- 支持创建多个独立角色，并显示角色名、等级、性别与职业。
- 当前创建入口开放战士；法师、道士显示为后续开放，避免进入未完成职业。
- 每个角色独立保存等级、经验、金币、背包、装备实例、技能、快捷栏、任务、设置及最近活动位置。
- 支持30秒周期自动存档，以及后台、失焦、关闭和关键数据变化时自动提交。
- 存档采用临时文件写入、旧档备份、原子替换；失败时尝试恢复旧档。
- 原有单角色v03/v02存档会迁移为“旧角色”，不会直接丢弃。
- 玩法场景保持独立，已有自动测试可绕过菜单直接验证战斗内容。

## 文件布局

- 角色索引：`user://character_profiles.json`
- 角色档案：`user://characters/<profile_id>.json`
- 自动备份：角色档案同目录下的 `.bak` 文件
