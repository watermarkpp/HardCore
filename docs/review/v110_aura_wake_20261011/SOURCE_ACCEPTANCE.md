# v110 引怪后追击许可修复：源码验收

## 根因与改动
普通近战怪的源码移动节拍只在发放当个 physics tick 保留许可，而300ms/分帧规划可能在另一帧可执行，造成合法许可丢失。目标已经选中不代表真正追击。毒蜘蛛的特殊攻击路径和暗之骷髅精灵的 Boss 路径不受同一门控影响。

生产修改仅 scripts/enemy.gd：保留一份绑定地图、区域代次、怪物生命、目标实例与目标生命的已授权追击许可；规划可执行后消费一次。不新增定时器、不提高预算、不补发移动节拍，不修改移速、攻击、HP、碰撞、掉落或地图。换目标、控制、魅惑、遗忘、取消及身份失效会退休许可。
