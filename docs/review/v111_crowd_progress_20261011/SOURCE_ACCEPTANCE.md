# v111 群怪持续追击：源码验收

基线：74d5816ed2b217294272db28f87fb89db9c5a8b7。本轮仅3份运行脚本及project.godot配置改动；保留110全部其他运行时内容。

## 修复范围
- FrameBudget将游戏进展与后台任务的准入分开。游戏进展初始机会为6000微秒/实际process周期，后台1200微秒；必要工作仍完整计入总账。不是OS频率设置或整个游戏CPU上限，不积累欠账，不按怪物/补物理步反复刷新额度。
- DecisionBudget让最老的五个就绪预留者可按实际节点回调次序完成；防止只等队头导致其余已到达的回调机会被浪费。保留同owner/同kind去重、生命/目标/地图身份核验、失效退休和有限维护。稳定scope不再每次重复复制及取消验证。
- PathScheduler使用同一游戏进展通道，保留原可恢复搜索、单次切片限制、回调和碰撞权威。
- 300ms重决策、110的合法移动许可保留、每物理步实际移动/碰撞、攻击和伤害、怪物HP、地图、资源素材和存档均不改。不启用旧dispatcher，不增加ECS/工作线程或无条件放开预算。
