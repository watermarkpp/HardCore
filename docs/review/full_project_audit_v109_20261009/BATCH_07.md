# B07 — 数据权威、生成构建、测试真实性与剩余代码

状态 `NOT_RUN`。主分组：`authoring_generation_build`、`data_authoring_identity`、`verification_and_tests`、`residual_review`，固定 SHA 由派发提供。规模较大，允许分子批；不得因规模大将剩余生产文件静默排除。

数据/生成追实际authority源、来源优先政策、stable ID、schema版本、精确目标更新、人工源字节绑定、编译器和消费者。难解析应定位解析器，不恢复fallback或手改生成物。工具的输出写入、覆盖、路径范围、dirty gate、退出和错误传播必须审查；不读取或写入凭据。

构建读取真实Android辅助源码与测试runner，检查source/engine/输入/scene/invocation/receipt/原生退出关联、stderr诊断是否遗漏、超时与隔离目录/互斥。默认关闭verbose诊断的新实现若进入固定源，按当批SHA检查，不把新日志当旧基线结论。

测试逐文件分类正式链/单位合同/模拟/fixture/历史；找绕过正式状态、缩负载/HP、放宽期限、弱化断言、未释放对象、重复无效测试及跨源码拼PASS。不要求重跑未变已验证项目。真实生产测试覆盖缺口与测试本身缺陷分别报告。

冗余分析必须追class_name/autoload/场景/资源/signal/Callable/动态call、编辑器与生成入口、兼容及存档消费者。搜不到普通调用不等于能删。退役格子路径只在本地时标缺口，不将其并回生产；删除建议由主控确认，不能直接删除。
