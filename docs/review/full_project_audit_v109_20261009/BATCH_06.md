# B06 — 存档平台、地图世界与发布生命周期

状态 `NOT_RUN`。主分组：`save_input_platform`、`maps_environment_streaming`，固定 SHA 由派发提供。

存档检查角色身份、版本/迁移、主备恢复、原子替换、异步writer/FIFO/回执、正常失败与临时pending、重入/退出/再次操作、进程中断恢复、死亡奖励与拾取跨链。仅存在backup或本地成功不等于完整事务保证；明确已持久化的状态与尚未生成的物品之间的恢复合同。不可增加第二写入权威或覆盖最新人工数据。

地图从map_editor_workspace与正式源→build service→运行发布registry→loader→READY→玩家/怪物/portal/安全区/碰撞/环境→换图代际与取消→重生占用/世界时钟→退出展开。发布源、视觉源、运行几何和持久地图身份必须一致。批量地图数据可用明确的结构/引用检查辅助审查，但不能把检查未覆盖的人工玩法标为逐行审核完成。

Android包名、签名、覆盖安装/版本与存档目录保持合同；本机临时路径/环境scope/preflight→导出→还原及失败边界需读真实代码。不开debug签名/卸载/降低versionCode绕过失败。

可分存档原子性与恢复、地图运行生命周期、世界时钟/重生、authoring发布接线、平台入口子批。标准报告要列哪些地图记录/字段实际被检查，哪项需要设备/故障注入而尚未执行。
