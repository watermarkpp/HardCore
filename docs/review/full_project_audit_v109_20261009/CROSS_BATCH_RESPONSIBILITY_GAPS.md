## Boundary notes

- A report count such as “50 functions” or “8 large files” was not copied as a fake function list. Where the source artifact did not name the remaining entrypoint, this matrix keeps the responsibility at the named module or marks the concrete name `MISSING` in the JSON source material rather than inventing one.
- `BLOCKED` means a user/product or authoring decision is required; `NOT_RUN` means a dynamic/native/device scope is absent; `MISSING` means a semantic responsibility or concrete source binding remains incomplete.
- The exact per-batch fixed SHA and report paths are recorded in the JSON so a later B07/B08 review can bind each item without treating this matrix as evidence that it inspected production code.
