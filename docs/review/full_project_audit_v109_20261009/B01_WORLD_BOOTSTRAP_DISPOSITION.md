# B01 world bootstrap disposition

Audited source: `dbd78d3301c2af6cfd9e070abe8cc847e6353175`. Repair snapshot: candidate tree `93d989012c55e087fa73486c56120ce01ce9fa8f`, parent `ed2d87121de80c84caaa3f096c3a5acb71d4946f`. Native evidence is recorded in `B01_NATIVE_VERIFICATION_LEDGER.md`; source implementation and native scope must be assessed separately.

The old initial timeout released the transition lock without invalidating the coordinator generation. A suspended world pipeline could resume and continue mutating the environment. The coordinator now retains a monotonic generation plus validity bit; failed finish/timeout revoke that owner before releasing its transition. `_world_pipeline_owner_current` checks generation validity, transition ID and transition-in-progress. Every asynchronous resume checks this boundary before further resource polling or environment mutation. A new begin advances and re-arms the generation.

The old generation also dropped accepted ResourceLoader requests when clearing its manifest. Each `OK` request is now counted as an owned claim. Current-generation terminal LOADED/FAILED claims are consumed; INVALID is not consumed again. Generation retirement and scene exit transfer remaining path/count claims to the existing persistent ContentLayers preparation service. The coordinator's retired path only transfers bookkeeping; it does not perform get calls in GameRoot process or teardown. Successful transfers are erased immediately, so partial failure does not duplicate previously accepted handoffs. There is no replacement loading authority or repeated request.

These prove their stated source/PC scopes. An actual 60-second asynchronous prefetch timeout race remains `NOT_RUN`; this fixture does not pretend the headless serial prefetch path exercises that race.
