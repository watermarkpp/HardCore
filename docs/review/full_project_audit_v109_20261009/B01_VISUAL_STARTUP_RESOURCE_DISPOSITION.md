Audit baseline: `dbd78d3301c2af6cfd9e070abe8cc847e6353175`. Tested repair tree: `93d989012c55e087fa73486c56120ce01ce9fa8f`. Exact engine contract: `B01_RESOURCELOADER_ENGINE_CONTRACT.md`; retained runs and limitations: `B01_NATIVE_VERIFICATION_LEDGER.md`.

Only an actual ResourceLoader request returning OK creates a local claim. Each accepted claim must eventually get once at LOADED/FAILED; status observation does not consume it. INVALID is not a second get. Scene retirement transfers remaining claims to existing ContentLayers, without requesting again or synchronously getting IN_PROGRESS. That existing service consumes one terminal claim per granted budget quantum; its global final shutdown retains the prior join contract.

Monster visual jobs now count accepted/consumed requests by path, preserving multiple actions using the same path. A partial failed job retains all unconsumed accepted sibling claims. Its orphan poll transfers claims into the bounded persistent service. GameRoot explicitly calls public retirement before disposing the RefCounted coordinator. PREDELETE is a protective static dispatch: the first native run exposed that calling a method on the dying RefCounted raised a null-instance error, so the final implementation uses a static seam with supplied dictionaries. This failure and its repair are retained in direct12/direct13 evidence.

MonsterSourceFrames still owns its normal bounded overlay poll (MAX_IN_FLIGHT unchanged). FAILED consumes the accepted claim; INVALID only clears bookkeeping. Its scene handoff transfers all remaining claims through `retire_pending_threaded_claims()`, now called from GameRoot exit.
