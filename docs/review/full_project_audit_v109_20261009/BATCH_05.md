# B05 — HUD、触控、Loading、音频与场景表现

状态 `NOT_RUN`。主分组：`audio_presentation_ui`、`presentation_scene_assets`，固定 SHA 由派发提供。

触控从屏幕坐标与view/stretch变换、事件路由、pointer身份/捕获/释放、模态/暂停、实际点击区域追到动作准入。重点检查同时移动、按住攻击/施法、四格药品快捷栏是否独立响应；图标中心/点击中心一致；摇杆、6技能、攻击、换敌与交互的实际布局和scale是否同步消费者。怪物血条填充/文字、战士开关居中、稀有名称金边与字号遵从已批准效果，不做新的视觉偏好选择。

逐文件/函数和scene/shader绑定留覆盖。布局截图、PC静态和Android多指/声音验收分别标范围；未运行则NOT_RUN。可分触控HUD、加载界面、效果表现、音频生命周期子批。
