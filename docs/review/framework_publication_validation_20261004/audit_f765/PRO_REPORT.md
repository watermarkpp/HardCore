### 修正边界应当怎么守

如果原生反例确认失败，应区分：

> **尚未开始释放：**原转场／死亡立即撤销旧生产资格并回收预留。  
> **已进入同步结算：**阻止新的释放，但让原批次持有它已经承诺的转移／消费容量，直到既有收尾完成。
