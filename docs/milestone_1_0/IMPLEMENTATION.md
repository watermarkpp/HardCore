# hardcore 1.0 正式版

本轮基线为用户已经接受的 v77：`0d3de7e7c254cab01bdeb051b8c74d68b0c98088`（APK 源 `59014144bd2730d39644db7853f479b94c5cebe7`）。仅重新开放人物属性显示、名称配色、抗拒火环中心，以及本次发布元数据。其余已验收内容冻结。

施工树 `codex/hardcore-1-0-milestone`，由同一主控串行负责 UI、技能与集成接线。`codex/integration` 与 v77 无分叉，后续按 fast-forward 合并。旧 bootstrap 只因专项分支不在路由表而失败，按 `docs/agent_rules/integration.md` 执行等价检查；旧主工作副本的用户 AGENTS.md 及所有既有未跟踪文件保留。

## 人物属性

- 原因：`AttributePanel/CharacterStats` 仍限高 220，旧物品属性区域已经隐藏。改为固定区域 218×534，第一行只有角色名（正文 +3），空一行后职业与等级（正文 +1），再空行显示属性。原窗口尺寸不变，无滚动条。
- 仅这两个控件使用 layoutRevision 1，旧校准数据不能把标题或短高度写回来。校准数据文件及其他按钮、格子、框图保持不变。
- 共用 `item_attribute_help.gd`，等级说明通过受控 Callable 读取 `PlayerState.experience / experience_to_next_level()`；字符名转义 BBCode。真实触摸、再次点击、关闭、内容更新及销毁清理均有测试。

## 名称配色

- `item_name_rarity_policy_v2.json` 是新显示策略，`build_item_name_rarity.py` 以冻结掉落分级表和装备主表的精确 ID 生成运行时配色。来源哈希采用 UTF-8/LF，跨 Windows checkout 可重复生成。
- 沃玛与同档亮金 `#FFD86B`；祖玛与同档橙色 `#FF943D`；赤月和极稀有紫色 `#C48CFF`；其余保留原 UI 普通色 `#E6DDCB`。
- 同档划分：记忆、祈祷、炼狱／魔杖／银蛇／无极棍、井中月归亮金；裁决／骨玉／龙纹、血饮、黑铁头盔、阎罗手套、虹魔／魔血归橙；赤月、六新衣、怒斩／龙牙／逍遥扇、屠龙／嗜魂、特殊功能首饰、35 级技能书归紫。回城卷修正为普通色；沃玛号角／祖玛头像分别亮金／橙。具体 241 项 ID 以策略和生成表为准。
- 装备基础属性、掉落分级、掉率、槽数、物品优先级均不变。普通名称不再因小极品变成另一个颜色；小极品有效性和地面光柱规则保留。
- 地面及拾取结果经正式 output_item_id 进入同一配色，界面显示名、价格、随机词条不能改写分级。批量拾取仍合并一次渲染。

## 抗拒火环

- 两处独立偏差：旧动画沿素材左上偏移显示（主帧视觉中心约偏移 -9/-42 px）；相邻八格判定围绕取整后的格坐标，站位有小数时整体偏移。
- 动画使用已有的整段可见边界居中策略，不改源图、大小、帧数或速度。
- 八个一格方块整体平移到施放时的人物脚下。Snapshot V2 新增可选 `cell_origin_offset_gu`，仅抗拒火环产生非零值；多边形、投影、AABB、圆形占位相交一致消费该偏移。去掉已有精确 snapshot 后重复执行的旧整数格筛选。
- 保持八格形状、中心空格、范围大小、等级限制、概率、零伤害、击退距离及路径碰撞。其他技能不写偏移，保持原快照字段和值。

## 验证

- 新功能：人物属性触摸、18 个名称颜色三端一致、抗拒火环 5 站位/40 边界样本及实际空间查询，全部 PASS。
- 12 项相邻回归首轮 11 PASS / 1 FAIL。失败为旧 W6 夹具访问仅耐久小极品的空 modifiers[0]；新规则本身已在 v77 存在。本轮改为追加明确非法 modifier，仍验证拒绝伪造；复验 PASS。未削弱断言或更改小极品规则。
- 非有限偏移拒绝、AABB 无多边形路径、共用装备属性说明、背包实际输入、关闭保护、拾取反馈与批量事务、范围快照坐标／身份、其他法师特效／范围及职业规则相邻测试 PASS。原始 runner JSON 留在 evidence。
- 本轮没有重新测量此前已经验收的多怪性能；未把导出成功当成手机帧率证明。构建、签名、最终源与 APK 字节核对见后续交付文件。
