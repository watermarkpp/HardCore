# 客户端全量资源目录

## 目录原则

- 文件名、数据库分类和人工文件夹名只表示来源，不表示真实用途。
- 完整客户端先做逐文件、逐容器、逐帧扫描；装备或动画查询只在全量知识库上执行。
- 所有正式采用资源必须能回溯到客户端、容器、帧号、切割公式、生成工具和验收图。

## SQLite查询示例

```sql
-- 每个资源库的扫描覆盖率
SELECT name, indexed_frames_scanned, valid_frames, decoded_head_candidates
FROM libraries
ORDER BY name;

-- 查询所有可能覆盖人物头部的帧，不限制原始文件类别
SELECT l.name, f.frame_index, f.width, f.height, f.draw_x, f.draw_y
FROM frames f
JOIN libraries l ON l.id = f.library_id
WHERE f.head_geometry = 1;

-- 按实际像素特征查看深色中性金属候选
SELECT l.name, h.frame_index, h.score, h.dark_ratio, h.neutral_metal_ratio
FROM head_candidates h
JOIN libraries l ON l.id = h.library_id
ORDER BY h.score DESC;
```
