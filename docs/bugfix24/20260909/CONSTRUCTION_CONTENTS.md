# HardCore 本轮施工内容列表

本轮整合：V3/R3 收尾方案、24 项施工包，以及用户后续属性面板和覆盖安装要求。

## 安装与存档

- 新版：72 / 1.21.0-r3-closure；包名继续为 `com.personal.mafaoffline`。
- 对照桌面的 `HardCore-20260906-gameplay-audio-debug.apk`（版本 71）验证签名一致、包名一致、版本递增。
- 直接打开新版 APK 覆盖安装，不先卸载。Android 替换旧程序和内置资源，并保留应用存档目录。
- 首次启动拒绝加载旧版本热更新包，并定向清理其 PCK 和启用清单；不扫描或清空人物、背包、装备、共享仓库目录。清理失败仍拒载旧内容。

## Android 持续攻击补充修复

- 攻击 action 必须由当前输入周期的新 DOWN 取得持有资格；暂停、失焦和 Loading 后不能凭遗留按下状态自动续攻。
- 系统菜单打开及恢复统一取消旧攻击、技能、摇杆输入，并直接清零玩家移动向量；保留其他来源已经持有的暂停。
- 摇杆过滤模拟鼠标、保持单一指针所有权，补齐控件外松手与取消；正常长按和双指分开释放保持原语义。
- 以上是已验证的软件缺陷修复；尚未在用户提到的三台故障手机复现并确认消失。

## 保留边界

- 正式装备属性、爆率概率/槽位/抽样、既有人工地图和素材保持保护；已授权行为数据、补图绑定等差异单独登记。
- 12 个缺乏精确 actor 来源的 ID 保持 DATA_HOLD，不猜配。召唤物缺少正式 `life_type`，不根据名称猜测线魔法的亡灵加成。
- 小极品默认 5% 产生一项 +1 是本轮工程默认，不冒称原版概率事实。
- Android 设备未连接；自动测试、桌面性能对照、APK 核验不替代实际安装和游玩验收。
