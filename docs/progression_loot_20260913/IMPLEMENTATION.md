## 根因与修改

- `profession_rules.gd`、`game_data.gd` 原来存在多套不完整的职业公式，`player_state.gd` 将魔法、道术、防御、魔防硬置零，敏捷统一为 15。现在从 server_rules 主源 `original_gameofmir/M2Server/ObjBase.pas` 的 `RecalcLevelAbilitys` / `RecalcHitSpeed`、`!Setup.txt`、`M2Share.pas` 编译唯一成长表；来源路径与逐文件 SHA 见 `assets/data/vanilla_176/character_base_growth_source_v1.json`。不使用装备库补裸属性。
- `tools/build_character_base_growth.py` → `scripts/generated/character_base_growth_v1.gd` → `ProfessionRules` → `PlayerState.base_stats/computed_stats`。战斗、显示与三项负重判定共同消费此链。旧 `BASE_STATS` 仅保留为历史导出元数据，已无正式属性计算消费者；旧 service 入口改为同源代理。
- 三职业一级裸值分别为：战士 HP19/MP15/攻击1–1；法师 HP16/MP18/攻击0–1/魔法0–1；道士 HP17/MP13/攻击0–1/道术0–1/魔防0–1/敏捷18。45级战士防御0–6、道士魔防4–9。Delphi Round 按最近偶数规则处理。21CQ 的 [45级裸防御](https://www.21cq.com/chuanqi/469.html)、[道士敏捷](https://www.21cq.com/chuanqi/538.html) 仅作旁证，未覆盖主源。
- 神水虽然已有到期函数，正式 `_process` 没有调用，因而效果一直持续。现在正常推进计时；加载角色清除未持久化的会话 Buff；使用失败同时回滚物品和 Buff。`player.gd` 修正 Buff 更新时先按比例改血再钳制的错误，保持绝对当前生命值并保护死亡状态。
- 12 种临时神水改为单个，祝福油、修复油、战神油保留单个规则。旧堆叠按用户选择：同页有空格便拆开，无空间保留原堆叠，不跨页、不丢物。背包提交及实际仓库双文件事务在同一提交中完成拆分；失败回滚。仓库整理仅处理当前 100 格页。
- JP 基础范围与追加数值合并；正式 JP 名称统一加 ★，覆盖物品面板、出售、地面与拾取。普通药水浅蓝，神水稍深蓝；神水显示真实效果及持续时间，未知内部字段不成为文案。
- `LootPreferences` 持久化三挡地面过滤。特殊/套装、JP、可用物品豁免；仅隐藏普通装备名称，保留图标并禁止自动/手动拾取。切换立即生效，设置关闭时保存。设置放在两条音量滑块下方。地面物品 600 秒回收，按出生顺序队列处理，每帧最多 32 个，避免每帧遍历所有物品。
