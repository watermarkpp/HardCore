# BICH-MAP-1 比奇区域地图骨架

- 设计尺寸：256×256 逻辑 Tile，64×32 等距网格。
- 城区：中央 64×64；安全区核心 32×32。
- 功能分区：中央广场、西侧补给、东侧交易、北侧任务、南侧锻造训练。
- 动线：四向主路与西南矿区支路。
