# BICH-MAP-1 比奇区域地图骨架

- 设计尺寸：80×80 逻辑 Tile，64×32 等距网格；由已完成的 64×64 内容四周各扩 8 格，内容不拉伸。
- 城区与安全区保持现有布局比例和世界坐标，仅整体平移至 80×80 画布中心。
- 功能分区：中央广场、西侧补给、东侧交易、北侧任务、南侧锻造训练。
- 动线：四向主路与西南矿区支路。
- 原版连接重组：沃玛森林、兽人古墓、毒蛇山谷、天然洞穴、比奇废矿。
- 地面：暗草地虚拟底图；城区使用石地、铺装路和泥地；道路使用土路变体。
- 工作文件：`map_editor_workspace/bich_province/bich_province.editor.json`。
- 地面工作区：`map_editor_workspace/bich_province/ground/`。
- 当前正式工作地图已包含 NPC、怪物刷新点和四个出入口；空模板入口不得覆盖该文件。
