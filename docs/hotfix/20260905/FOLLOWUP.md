# 死亡后怪物空身、死亡经验与音乐音量跟进

## 用户确认范围

- 死亡扣本级从 0 升到下一级所需总经验的 10%，不是已有经验或剩余经验的 10%；采用当前游戏升级门槛，向下取整，最多扣至 0，不降级。
- 主城音乐默认线性音量为原来的 70%；触发区域、延迟与单次播放不变。
- 怪物空身需查公共根因，不仅修多钩猫或比奇；用户补充出现问题前人物死过一次。

## 公共调用链问题

`travel_to_service_home` 在同地图死亡回城时仍启动 Loading 过渡；`_run_map_transition` 原先无条件调用 `begin_map_prefetch`。后者增加资源 generation 并注销旧视觉订阅。随后 `_load_zone` 遇到同区域、同地图立即返回，不重建旧 EnemyActors。旧怪仍有名字/血条，但被注销后无法再次请求身体资源；后续刷新的新怪不受同一次注销影响，因此出现多种怪物间歇空身。

修复集中在 GameRoot 的 `_begin_monster_transition_prefetch`：同图且非初始 bootstrap 时保留现有 generation 和资源订阅；跨地图或初始进入仍走原代际隔离。没有扩大驻留距离、关闭预算、修改 AI、增加怪物种类或改素材。
