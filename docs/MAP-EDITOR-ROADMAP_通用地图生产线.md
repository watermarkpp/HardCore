# 通用地图生产线实施总纲

本任务以“专用地图编辑器完整方案 v1.0”为正式需求基线。编辑器不绑定比奇；比奇只作为第一张闭环样板。

核心架构固定为：素材库驱动 + 十层地图 + 网格/像素双坐标 + 模板/实例分离 + 独立碰撞逻辑层 + JSON导出 + 游戏运行时同源读取。

## 阶段

1. `MAP-EDITOR-CORE`：Schema、素材扫描、模板目录、多地图工程结构。
2. `MAP-EDITOR-CANVAS`：通用画布、十图层、网格、缩放、平移、选择、绘制、保存读取。
3. `MAP-EDITOR-PLAYABLE`：碰撞、NPC、刷新点、出生/传送/区域、检查器、游戏读取。
4. `MAP-EDITOR-ART`：自动道路/过渡/墙体/栅栏、随机撒布、遮挡、小地图。
5. `MAP-EDITOR-PRODUCTION`：元数据编辑、批量导入、版本管理、模板地图和多地图管理。

## 当前状态（2026-07-05）

- `MAP-EDITOR-CORE`完成。
- 已建立十层Schema、九类碰撞编码、十一类区域、地图实例目录和Godot校验加载器。
- 素材自动扫描结果：图像模板131、怪物模板214、NPC模板19。
- `MAP-EDITOR-CANVAS/PLAYABLE v1.0`完成：支持矩形地图创建、十图层、地形/碰撞、对象、NPC、怪物刷新、出生点、传送点、矩形区域、属性编辑、撤销重做、检查器及map/collision/nav/preview导出。
- 下一任务仅剩游戏侧完整渲染接入与比奇导出文件闭环验证；编辑器自身已可投入地图设计。
