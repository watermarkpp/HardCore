# 三职业技能战斗参数基线 v1

用途：手机自动选敌、人物转向、动画命中帧、技能执行器和特效落点的共同基线。

重要说明：数据库学习等级与部分效果为A/B级资料；攻击距离、前摇、命中帧和冷却目前是运行时候选值，不代表已经完成官服逐帧核验。

## 统一字段

- `cast_type`：执行类型。
- `target_mode`：`self`、`self_area`、`single`、`direction`或`target_area`。
- `range`：技能作用距离，单位为逻辑像素；32像素约等于一格。
- `search_range`：手机自动选敌搜索距离。
- `multiplier`：职业主属性随机值的伤害倍率。
- `area_radius`：作用半径或直线宽度。
- `windup`：按钮按下至命中/发射的时间。
- `hit_frame`：六帧攻击/施法动画中的关键帧。
- `cooldown`：当前技能公共出手间隔。
