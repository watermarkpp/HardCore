# BICH-BOSS-1：骷髅精灵与尸王校准报告

日期：2026-07-03

## 结论

- 服务端 `M2Server/UsrEngn.pas` 将 Race 89 和 `MONSTER_OMAKNIGHT`（81）均实例化为 `TATMonster`；两者采用标准主动近战怪物状态机。
- `M2Server/ObjMon.pas` 证明无目标时约1秒搜索、持有目标时约8秒重新搜索，并在攻击前重新计算方向。
- 当前服务端源码未发现骷髅精灵半血狂暴、扇形重击，或尸王范围震地机制；项目原有三项效果已关闭，不再冒充1.76机制。
- 骷髅精灵采用500 HP、7—24攻击、2.0秒攻击间隔；尸王采用500 HP、18—36攻击、2.8秒攻击间隔。类映射与状态机为A级证据，名称到Race、属性及速度为B级候选。

## 运行接入

- 新增 `assets/data/boss_service_rules.json`，集中维护AI类别、属性、攻击/移动时序、命中帧、目标刷新和技能开关。
- `GameData` 启动时载入Boss规则；`EnemyActor` 按规则执行持续朝向、攻击期间静止、客户端命中帧延迟结算和8秒目标刷新。
- 骷髅精灵攻击动画/命中帧为600/300ms；尸王为720/360ms。两者攻击间隔独立于动画时长。
- 保留Boss抗普通推动、薄脚底选中圈、视觉脚底锚点和大型名称高度，选中后不改变怪物垂直位置。
