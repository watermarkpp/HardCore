# UI-GOTHIC-PREVIEW-1 暗黑哥特界面审图样板

日期：2026-07-16  
状态：已完成视觉样板，等待用户审图；尚未接入正式游戏，尚未打包 APK。

## 本轮交付

- 人物选择与人物创建合并为同一界面：左侧已有角色、中间人物实装预览、右侧创建人物。
- 创建人物可直接选择战士、法师、道士；三职业均按可选状态设计，不再沿用旧界面仅战士可用的临时表现。
- 游戏内退出界面统一为暗黑哥特弹窗，保留继续游戏、返回人物选择、安全退出与安全回城说明。
- 游戏 HUD 统一为黑曜石、旧黄铜、血红余烬视觉；人物不显示横向血条/蓝条，使用《Diablo 1》式左红血球、右蓝球；顶部只显示怪物目标血条。
- HUD底部开放4格战斗物品栏，可放药水、回城卷、随机传送卷等。轻触立即使用，长按弹出该格的物品选择菜单；血瓶与蓝瓶仍可按自动补给规则使用。
- 三个战士技能开关位于4格物品栏上方，战斗物品与技能控制分层显示。
- 基本剑术和攻杀剑术属于后台常驻被动，不在HUD技能区显示。
- 刺杀剑术、半月弯刀、烈火剑法以自动施放开关呈现，点击一次开启、再次点击关闭。
- 野蛮冲撞不进入技能开关区，也不与普通攻击互斥；它作为攻击键旁的一次性按钮，点击一次立即使用。普通攻击始终保持可用。
- 右下攻击按钮周围固定3个技能按钮，用于安放人物技能；战士技能按钮轻触立即使用，法师/道士技能按钮用于选择当前施法技能。
- 新增独立技能页面：展示人物全部技能及名称、等级、熟练度、类型、魔法消耗、冷却、范围、说明和数据依据。长按技能后弹出“技能按钮1/2/3”目标选择。
- 战士保留刺杀、半月、烈火三个自动开关；法师和道士不显示自动开关层，只通过右下三个技能按钮管理施法技能。
- 技能每行最多4个，超过4个自动进入第二行；红血球与蓝球固定在技能区两侧。
- 法师和道士复用同一布局，但技能按钮改为互斥选择；攻击键显示为“释放技能”，并将“普通攻击”作为可选择项。
- 右侧保留“切换敌人”和“自动锁定”控制；右下战士只显示“攻击”，法师/道士只显示“释放技能”。“当前追踪”任务面板不进入HUD。
- 右下技能圈之外、屏幕最右侧设置一个独立“交互”按钮；只执行最近可交互目标的交互动作，不占技能槽，也不复用攻击、施法、切换敌人或自动锁定功能。
- 底部生命球与魔法球分别紧贴中央技能开关/物品控制台左右两侧，形成“生命球—中央控制台—魔法球”的稳定结构；右下主要操作区增加按钮留白，所有交互热区互不重叠。
- 视觉统一为清爽的远古哥特：深黑石质底、细铜金双线、克制的暗红菱形装饰；不叠加污渍、噪点或脏旧纹理，优先保证信息和触控区清楚。
- 非交互面板执行现代暗黑 ARPG 全透明规则：背景透明度固定为 0，只保留细铜金框、黑铁角饰和暗红宝石节点；只有技能格、物品格、功能按钮、血球和蓝球保留明确实体质感。
- 技能图标不得由生成图冒充：刺杀、半月、烈火直接取自主客户端`Magic.wil`验收运行图集，野蛮冲撞使用实际游戏冲锋画面。生成美术只允许用于普通攻击、交互、切敌、自动锁定、地图等非技能功能。
- HUD审图底图由`tests/ui_clean_world_capture.tscn`从当前正式场景隐藏旧HUD后生成，确保透明面板后显示的是真实游戏世界，而不是黑色假背景或旧UI残影。
- 左上角不显示人物名称、等级或职业卡片。自动锁定进入屏幕右侧固定功能栏；切换敌人紧邻右下攻击/释放技能按钮，便于战斗中即时触发。右侧功能栏为后续功能保留纵向扩展空间。

## 美术规则

- 主材质：黑曜石、黑铁、旧黄铜、暗红珐琅。
- 状态色：普通为骨白，重点为旧金，选中/危险为血红，生命恢复提示为灰绿，魔法资源为深蓝。
- 新生成的大厅背景属于 `project.generated.ui_preview`，仅服务本项目 UI 表现，不参与传奇客户端资源优先级，也不替代任何主客户端装备、NPC、怪物或物品素材。
- 中文文字全部由 Godot 字体实时排版，没有烘焙进位图，便于后续分辨率适配和文案修改。
- 1280×720 样板中的触控目标按不小于 56 像素设计。
- 中央控制台不再建立整体外框或底板；技能格与物品格独立分层排布，生命球和魔法球分别位于左右两侧。
- 哥特美术使用代码原生矢量线框、角括饰、黑铁矛翼、金色夹具与暗红菱形节点，保持透明场景可读性，不使用大面积遮罩或脏旧噪点。
- 用户复审后删除中央500×204金色大外框；下方改用生成式黑铁/旧金组合骨架，左右圆环分别包住生命球与魔法球，中间只保留开放式桥梁装饰，没有中央矩形或实体面板。
- 技能开关、四格物品栏和右下技能按钮统一使用生成的透明中心哥特插槽框。技能框与技能图像严格分层：外框固定，技能改变时只替换内层实际游戏技能纹理；物品图标同样位于固定框内。
- 已删除资源球附近旧代码绘制的四个菱形夹块；资源球外观只由组合美术圆环承担，不再叠加重复饰件。
- 生成源图和去底母版归档于`dev_art_sources/ui/gothic_hud_v1`，运行目录只保留由`tools/build_gothic_hud_runtime_assets.py`生成的轻量贴图。
- HUD V2不再用目测摆放内容：`tools/ui_frame_geometry_opencv.py`通过透明通道连通域与距离变换测量图框空白区，组合骨架的生命/魔法孔圆心分别为`(96,82)`、`(743,82)`，半径均为`42.9418`；运行时红蓝球由该几何清单反算位置和尺寸。
- 三套圆形按钮框候选经OpenCV比较后选择B方案；128×128运行框透明孔圆心为`(63,62)`、半径为`36`，轮廓圆度`0.846428`。四个物品格固定为74×74正方形，并按96×96方框实测透明孔缩放图标。
- 技能/功能内容与装饰框严格分层：内容在下、框体在上、文字置顶；每个按钮只允许一个名为`Icon`的动态图层。按用户复审要求，图标不做去背景或人物/武器抠图，完整源画面采用cover策略覆盖装饰框空白区，再由顶层框体压边。
- 可复建工具为`tools/build_gothic_hud_v2_assets.py`和`tools/build_hud_runtime_icons.py`；几何清单为`assets/ui/gothic_preview/frames/gothic_hud_frame_geometry_v2.json`，图标来源清单为`assets/ui/gothic_preview/icons/runtime_v2/runtime_icon_manifest.json`。
