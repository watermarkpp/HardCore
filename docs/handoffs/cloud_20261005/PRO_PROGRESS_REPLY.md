完整计划应在原地图发布/进入READY之前由作者数据和正式生成物产生，只读绑定Root/world、revision/hash、base slots、descriptor、碰撞/导航、respawn和召唤共享配额。它不是第二可编辑数据库。登记monster ID不授予新slot，READY不授予任意descriptor资格；当前活世界不消费未发布的新配置。

活动状态头数N×sum(L_k)不包括全部旧root、receipt、资源、旧life尾部与inflight。即时有限链上界N×sum_g((N×B)^g)也不是全部周期累计执行量。分别证明内存、累计工作和最大服务延迟。
