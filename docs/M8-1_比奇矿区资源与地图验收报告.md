# M8-1 比奇矿区资源与地图验收报告

## 结论

401—412已从“共用兽人古墓图集的批量模板”升级为“经典客户端MAP映射驱动的矿区垂直切片”：使用矿区专用地砖、岩壁、木支架、矿轨、矿车、桥梁、碎石、矿灯和竖井入口，并为每张地图生成不同线路枢纽、碰撞和灯光配置。

这一步完成的是适合当前手机战斗场地的压缩重构，并非逐格复刻200×200原地图。原始可行走掩码和统计已经保存，后续可以继续向逐格地形逼近。

## 服务端与客户端来源

- 服务端规则：`research/MIR2/GameOfMir/M2Server/Envir.pas`中的`TMapHeader`、`TMapUnitInfo`和阻挡位定义。
- 客户端地图：`research/mir2_client_raw/Map/*.map`，直接解析宽高、背景/前景阻挡位、Area、门、动画和灯光单元。
- 客户端美术：`Tiles.wil/.WIX`与`Objects2.wil/.WIX`。
- 项目结构化数据：`assets/data/legend176_data.json`的地图名称、怪物、Boss和掉落。
- 辅助核对：21CQ地图页与传统客户端MAP文件名索引；由于当前服务端包仍缺`MapInfo.txt`，门点坐标暂以项目既有闭环为运行基准。
