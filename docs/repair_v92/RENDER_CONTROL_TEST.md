- 同一份当前工作树源码，仅切换生产路径已有的调试开关 `WALL_RENDER_FORCE_LEGACY`。每图LEGACY、OPTIMIZED各两次，第二轮反向执行，共12次；所有runner均PASS、0引擎错误。
- 通过真实主场景、地图转移、正式刷新点和正式火墙释放入口；黑暗地带62怪、死亡棺材71怪、抉择之地54怪。每次8场火墙，每场9格，240物理帧采样；没有减少怪数、碰撞、火墙频率或内容。
- 新增实际模式断言、完整初始怪物布局哈希、相机位置/缩放与物理对象计数。12次结果逐项核对一致；每场火墙均5个tick，重复伤害计数0，移动方向不一致计数0。各图4次火墙伤害应用数分别固定53、43、42。
- 物理环境精灵计数包括动态排序子精灵、静态精灵、墙影块与桥接叠层；既统计Background下的静态物体，也统计世界Y-sort根下的动态墙。统计在采样结束后执行，避免遍历影响计时。
- Godot使用headless显示与虚拟渲染；这里的process间隔、CPU和精灵对象数不是手机FPS、GPU时间或真实draw-call数量。CPU总量受实际唤醒次数影响，另按enemy physics调用次数归一化，不拿总量差异代替每次成本。

当前基线HEAD为 `b961cedff8040c9fc81534e094241ad9fa2330ad`，测试使用未提交的v92修复源码。精确源码哈希、12份原始采样、12份runner结果和12份控制台见 [comparison.json](evidence/render_control/comparison.json) 及同目录；生成工具为 `tools/performance_v92/compare_render_controls.py`。不能把基线HEAD误写成已包含本次修复的提交。
