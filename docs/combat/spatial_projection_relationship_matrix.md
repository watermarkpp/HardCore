# 战斗空间投影关系矩阵

## 目标

本文件定义“技能、攻击、可见效果与地面投影”的关系。它不是把所有技能强行改成同一种形状，而是要求每次具有空间含义的释放先生成一份只读地面 GU 投影快照，再由命中、位移、持续效果、有效视觉核心、预警和诊断共同读取。

正式来源：

- 技能身份、形状和语义：`skills.mir2_176.vanilla_33.v1.0.1`
- 地面单位与投影：`combat.unit.gu_gs_px.v1`
- 人工玩家/怪物脚点和怪物占地：已冻结的运行时合同，只读使用

## 投影关系类型

| 关系 ID | 含义 | 视觉与判定关系 |
|---|---|---|
| `release_contact` | 近战接触/短距离单体 | 从攻击者释放帧脚点生成攻击投影，与目标战斗脚印相交；武器残影不是额外伤害区 |
| `directed_core` | 直线、扇形或定向区域 | 动画的“有效核心”与投影重合；辉光、拖尾和粒子可越界，但不得参与伤害 |
| `ground_exact` | 地面持续区或明确的离散地面区域 | 可见地面有效区、持续/瞬时效果区和投影边界完全重合 |
| `projectile_sweep` | 有飞行过程的弹体 | 弹体中心沿同一 GU 路径移动，弹体半径形成扫掠投影；命中后若有爆炸则另建爆炸投影 |
| `target_footprint` | 指定单体 | 选中的是目标实例；实际空间落点为目标释放帧脚点及其战斗脚印，不以贴图中心或身体像素判断 |
| `movement_sweep` | 冲撞、击退、传送、出生位置 | 路径/目的地/占位使用投影；没有伤害时也不能绕过地面空间合同 |
| `attached_state` | 附着在施法者或目标身上的状态视觉 | 以宿主脚点/脚印作为视觉锚点，不创建虚假的范围伤害 |
| `inherits_release` | 被动、概率增伤、充能 | 自身不另建攻击区；严格继承本次宿主攻击唯一快照 |
| `non_spatial` | 纯数值被动 | 不创建伪造投影 |

## 玩家普通攻击与战士

| 行为/技能 | 投影关系 | 正式投影 | 锚点与朝向 | 约束 |
|---|---|---|---|---|
| 普通攻击 | `release_contact` | 1.5 GU 单体近战投影 | 人物释放帧脚点；本次攻击冻结朝向 | 最多结算一个相交目标；目标脚印可擦边命中 |
| 基本剑术 | `inherits_release` | 继承宿主近战投影 | 无独立锚点 | 只提供常驻准确，不生成攻击区 |
| 攻杀剑术 | `inherits_release` | 继承宿主有效近战/近战技能投影 | 无独立锚点 | 概率准确/伤害修饰不能另播一次独立攻击几何 |
| 刺杀剑术 | `directed_core` | 2.5 GU × 1 GU 前向直线 | 释放帧脚点与冻结方向 | 动画有效剑气核心、伤害和诊断共用快照；所有相交目标按正式分段语义结算 |
| 半月弯刀 | `directed_core` | 随八方向旋转的前方四向弧区 | 释放帧脚点与冻结方向 | 不是圆形；可见刀光核心与弧区一致，目标用脚印相交 |
| 野蛮冲撞 | `movement_sweep` | 最长 3 GU 的角色/目标扫掠路径 | 人物脚点到合法目标脚点的冻结方向 | 动态阻挡取消、静态阻挡截短；位移轨迹和碰撞预检共用快照 |
| 烈火剑法（充能） | `inherits_release` | 充能时无投影；消耗时继承实际近战释放投影 | 继承被消耗攻击 | 不能单独生成更长或更宽的伤害区 |

## 法师

| 技能 | 投影关系 | 正式投影 | 视觉/效果关系 |
|---|---|---|---|
| 火球术 | `projectile_sweep` | 弹体 GU 路径与弹体半径扫掠 | 弹体视觉中心沿同一路径；碰撞目标使用脚印 |
| 大火球 | `projectile_sweep` | 当前正式语义为单体弹体扫掠 | 不擅自添加范围爆炸；若主源以后定义爆炸，再为命中点建立第二阶段投影 |
| 抗拒火环 | `ground_exact` + `movement_sweep` | 施法者周围相邻环形格区的精确并集 | 火环有效地面区与候选区一致；每个被推动目标再建立独立位移路径 |
| 诱惑之光 | `target_footprint` | 被选怪物的释放帧战斗脚印 | 光效中心落在目标脚点；控制结果只作用该实例 |
| 地狱火 | `directed_core` | 5 GU × 1 GU 前向矩形，受地形截短 | 火焰有效核心、伤害矩形、地形截短和诊断共用同一快照 |
| 雷电术 | `target_footprint` | 被选目标战斗脚印 | 雷击落点为目标释放帧脚点；闪电外发光不扩大命中区 |
| 瞬息移动 | `movement_sweep` | 合法目的地玩家脚印 | 到达动画以目的脚点为中心；不是向前伤害投影 |
| 爆裂火焰 | `ground_exact` | 目标/选点脚点为中心的 3×3 地面格区并集 | 一次爆炸有效地面区与瞬时伤害投影重合；粒子外溢不伤害 |
| 火墙 | `ground_exact` | 冻结的 2×2 地面格区并集 | 火焰可见有效区、每跳伤害区和持续区域完全重合；同一目标同一时刻只结算一个火墙伤害 |
| 疾光电影 | `directed_core` | 8 GU × 1 GU 前向矩形，受地形截短 | 光束有效核心、贯穿伤害、长度/宽度和诊断共用快照 |
| 地狱雷光 | `ground_exact` | 施法者脚点周围、排除中心的半径 2 GS 环形格区并集 | 这是主源明确的离散环区，不改成欧氏圆；动画有效地面区与候选区一致 |
| 魔法盾 | `attached_state` | 玩家战斗脚印仅作为附着/居中投影 | 没有伤害区；盾持续视觉始终以人物脚点为中心并处于正确遮挡层 |
| 圣言术 | `target_footprint` | 被选不死怪物的战斗脚印 | 结果只作用该实例，不把视觉闪光当群攻区 |
| 冰咆哮 | `ground_exact` | 目标/选点脚点为中心的 3×3 地面格区并集 | 冰暴有效地面区与瞬时伤害投影重合；装饰粒子不扩大范围 |

| 神圣战甲术 | `ground_exact` | 选点为中心、半径 3 GS 的格区并集 | 友方目标脚印与区域相交才获得状态；视觉有效区一致 |
| 心灵启示 | `target_footprint` | 玩家或怪物目标脚印 | 信息揭示只作用选定实例 |

## 召唤物攻击

| 攻击者 | 投影关系 | 要求 |
|---|---|---|
| 骷髅近战 | `release_contact` | 骷髅释放帧脚点生成近战投影，与怪物脚印相交；不得只比较两个中心点 |
| 神兽定向攻击 | `directed_core` | 神兽释放帧脚点和冻结方向生成方向投影；喷火有效核心、伤害与诊断共用快照 |
| 其他召唤物弹体（若正式定义存在） | `projectile_sweep` | 弹体沿地面 GU 路径扫掠，命中目标脚印；不能复用主人脚点 |

## 怪物与 Boss

| 攻击类型 | 投影关系 | 要求 |
|---|---|---|
| 普通怪物近战 | `release_contact` | 怪物释放帧脚点到玩家脚印；保留正式攻击距离，不按玩家贴图中心判定 |
| 怪物定向/扇形攻击 | `directed_core` | 怪物释放帧脚点和方向生成直线/扇形快照；动画有效核心和伤害共用 |
| 怪物远程弹体 | `projectile_sweep` | 怪物脚点起射，地面 GU 路径扫掠玩家脚印 |
| 怪物/Boss圆形或格区攻击 | `ground_exact` | 预警、伤害、调试显示读取同一次释放快照；玩家脚印与区域相交才受击 |
| Boss预警后延迟伤害 | `ground_exact` 或 `directed_core` | 预警开始时冻结唯一快照，延迟结算不得重新读取移动后的施法者脚点或重新生成不同形状 |
| 怪物锁敌、警戒、追击 | 非攻击投影 | 继续使用正式 GU 选择域；不伪装成伤害范围，也不能反向改写攻击快照 |

## 强制不变量

1. 每次空间释放只有一个 `release_id` 和一个只读投影快照；分阶段技能每个阶段各有明确父子关系。
2. 攻击者使用释放帧脚点，目标使用同一结算时刻的战斗脚印；不得混入贴图左上角、屏幕缩放或 UI 坐标。
3. `PX` 只由快照投影得到；伤害代码禁止反过来读取动画尺寸或屏幕像素。
4. `ground_exact` 必须精确保留格区并集的凹口和空洞，不得用包围矩形或外接圆替代。
5. 目标是否命中以“目标战斗脚印与技能投影相交”为准；禁止退化成目标中心点测试。
6. 装饰辉光、拖尾、尘雾和武器残影可超出有效核心，但必须有明确的非伤害身份。
7. 人工玩家/怪物脚点、怪物占地与已验收素材只读；本施工不得批量重建或归一化它们。

## 2026-08-03 实施与验收

- 33 个正式职业技能由机器合同 `skills.spatial_projection.relationship_matrix.v1` 唯一分类；生产空间技能缺少同一 `skill_id` / `release_id` 的只读快照时直接阻止执行，旧测试兼容仅允许显式的非生产适配器。
- 玩家普通/烈火/半月/刺杀、野蛮冲撞、精确地面技能、单体目标技能、传送目的地、召唤出生和后续召唤物攻击均已接入对应快照；道士群体效果使用稳定目标实例 ID，不依赖数组顺序。
- 三种正式投射物（小火球、大火球、灵魂火符）在释放帧创建完整 GU 飞行走廊母快照；每个物理帧再创建带 `parent_snapshot_id` 与递增 `segment_index` 的实际扫掠子快照，碰撞使用弹体半径与目标战斗脚印连续相交，防止高速穿透。
- 怪物普通近战、远程攻击、固定区域、Boss 扇形/圆形与延迟预警伤害共用释放快照；预警与结算不重读移动后的施法者位置。人工玩家/怪物脚点与怪物占地只读。
- 验收结果：职业技能目录 `27/27`、怪物套件 `18/18`、战士/法师集成套件 `25/25`、最终关键套件 `87/87`，全部通过项目规定的 headless 测试入口。
