# SkillFootprintSnapshot 迁移审计（v1）

正式原则：伤害、碰撞与目标判定只读取连续地面 `GU`；屏幕 `PX` 四边形只能由同一次释放的 ground-GU footprint 单向投影得到，绝不反向参与判伤。每次释放以稳定 `skill_id + release_id` 标识，并生成只读快照。

| 系统 | 正式 shape_type | 当前结论 | 原因 |
|---|---|---|---|
| 法师地狱火 `5×1 GU` | `directed_rectangle` | 本次迁移 | 伤害和稳定视觉核心可消费同一有向矩形快照。原火焰节点保留正常装饰强度，不定义边界。 |
| 法师疾光电影 `8×1 GU` | `directed_rectangle` | 本次迁移 | 伤害和稳定视觉核心可消费同一有向矩形快照。原序列为装饰层，不定义边界。 |
| 战士刺杀 `2.5×1 GU` | `directed_rectangle` | 本次迁移 | `long_hit` 是严格八方向素材，因此伤害轴恢复为同一八方向轴，不再向锁定目标连续弯折。 |
| 战士半月 | `sector_arc` | 分类，暂不迁移 | 当前是多个方向扇区组合，不是单个直线矩形；仍以 ground-GU SAT 判定。 |
| 战士野蛮冲撞 | `swept_capsule_path` | 分类，暂不迁移 | 核心是路径、静态障碍截断与动态阻挡的原子位移，不是一次矩形伤害区。 |
| 法师/道士区域法术 | `circle` / `target_footprint` | 分类，暂不迁移 | 需保持目标脚点圆域或目标占地，不能强行套直线。 |
| 技能投射物 | `swept_capsule_path` | 分类，暂不迁移 | 当前已使用 ground-GU/s 移动与扫掠接触；移动 footprint 随时间推进，不是释放时固定矩形。 |
| 被动、增益、护盾 | 无伤害 footprint | 不生成 | 它们没有空间伤害边界；禁止为显示方便伪造 PX 判伤区域。 |

本次没有修改正式射程、宽度、人物/怪物人工脚点、怪物占地、头盔、装备或源 PNG，也没有运行素材生成器。后续 shape builder 扩展必须继续复用统一 projection API，并为对应形状补齐边界与实机一致性测试后才能迁移。
