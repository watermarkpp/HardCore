## 完成内容

- 为稻草人、钉耙猫、多钩猫、半兽人、半兽战士、森林雪人、食人花、毒蜘蛛、骷髅精灵、尸王接入独立运行掉落表。

- 社区候选由375条扩展至429条；357条后期物品、异常概率或非白名单记录继续隔离。
- 怪物死亡结算优先读取校准表；没有校准表时继续使用既有Boss或区域掉落，不破坏洞穴、矿区现有闭环。
