## 坐标规则

- 新增 `MapCoordinateMapper`，统一执行原MAP坐标与Godot世界坐标的双向转换。
- 每个逻辑格采用64×32菱形地砖：横向、纵向半格分别为32和16像素。
- 地图以原尺寸中心为世界原点；700×700地图世界边界为 `Rect2(-22368,-11184,44736,22368)`，400×400地图为 `Rect2(-12768,-6384,25536,12768)`。
- 服务端出生点 `(289,618)` 直接映射为 `(-10528,3328)`，不再压缩到 `(0,80)`。
- 怪物、Boss、NPC和门点统一保存 `source_coordinate`，运行位置从同一公式生成；双向转换可恢复原坐标。

## 手机性能策略

- 世界尺寸保持完整，但背景只绘制镜头附近57×57逻辑格。

- 六张地图均增加四条原尺寸边界碰撞，角色不能离开原MAP菱形范围。
- Camera2D继续跟随角色，地图扩大不会改变HUD、攻击按钮或自动选怪操作。
