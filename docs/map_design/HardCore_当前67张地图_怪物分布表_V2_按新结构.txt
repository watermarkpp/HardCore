一、编制规则与重要说明
======================================================================

1. 地图名称、尺寸、map_id、runtime_id 和连接层级全部以当前新的 67 张地图结构表为准。
2. 旧怪物分布中仍存在于当前地图系统的内容优先继承；已经取消的中继地图不会重新加回。
3. 当前地图系统发生压缩时，会把被取消地图中“有必要保留的怪物内容”合并到最合理的现有地图，并在备注中标成【压缩合并】。
4. 六大重装隐藏地图已全部补齐，默认均作为专属 Boss 房，不额外铺普通怪。
5. 本表只确定“每张地图刷什么怪”，不擅自确定刷新数量、半径、时间和精英概率；这些应结合地图实际尺寸另做密度表。
6. “特殊/守卫”不是普通怪群。弓箭护卫、恶魔弓箭手、宝箱怪、未知暗殿变体应按各自系统实现。
7. 未知暗殿、极品祖玛等同名不同模板怪，必须使用稳定 monster_key + variant；不要依赖数组顺序、临时数字 ID 或显示名称。

六大重装 Boss 对应：
  困惑殿堂 → 暗之双头血魔
  地狱烈焰 → 暗之骷髅精灵
  堕落坟场 → 暗之黄泉教主
  死亡神殿 → 暗之虹魔教主
  深渊魔域 → 暗之双头金刚
  钳虫巢穴 → 暗之沃玛教主

九、这次相对旧怪物分布的关键调整
======================================================================

1. 石墓四层：
   因石墓五层、石墓阵、六层、七层已从当前项目取消，
   把白野猪、邪恶毒蛇、石墓尸王集中到石墓四层，保证石墓后段核心怪/BOSS没有被一起删掉。
   早期资料中的“邪恶蜈蚣”不作为默认石墓BOSS启用。

2. 祖玛阁：
   因祖玛五层、六层大厅、七层已取消，
   把深层极品祖玛弓箭手、极品祖玛雕像、极品祖玛卫士并入祖玛阁。
   玩家显示名称仍然是祖玛弓箭手/祖玛雕像/祖玛卫士，内部用 variant 区分。

3. 毒蛇山谷连接通道：
   当前山谷矿区一/二层已取消，主入口直接进入连接通道1。
   因此连接通道1补入洞蛆；连接通道2补入洞蛆和稀有尸王。
   连接通道2只进入未知暗殿，不再连接死亡山谷。

4. 封魔谷崎路：
   新结构已经明确 fengmo_forked_path 属于封魔谷，不再属于蜈蚣洞。
   因封魔矿区、封魔连接通道被压缩掉，崎路承担其基础僵尸/洞蛆以及尸王内容。

5. 赤月峡谷：
   原怪物表把北/南/东峡谷分别列出；当前只有一张 32×128 的赤月峡谷，
   所以三张峡谷的同类怪物池统一合并到当前赤月峡谷。

6. 六大重装隐藏房：
   六张地图全部存在于当前结构，因此全部恢复完整对应 Boss，默认不放普通小怪。

7. 鹰卫：
   旧怪物表把鹰卫放在丛林迷宫，但当前地图结构已经取消丛林迷宫。
   本表没有擅自把鹰卫塞进赤月峡谷。
   如果项目仍保留鹰卫/诱惑玩法，可另行决定在白日门边缘设置固定刷新；否则可以完全不刷新。

8. 尸魔洞怪物：
   当前地图结构没有尸魔洞，所以旧表中的恶灵僵尸、恶灵尸王没有强行迁移到骨魔洞。
   这样能保持骨魔洞的骷髅主题完整；以后若重新启用尸魔系内容，再单独恢复。

9. 非严格 1.76 扩展项：
   盟重省“神鹰”默认关闭。
   牛魔寺庙大厅“暗之牛魔王”默认关闭。

10. ID/模板安全：
    未知暗殿真假怪、祖玛极品变体等必须保存稳定 monster_key 和 variant。
    不允许再用“怪物列表第 N 项”或可变数字序号做地图持久化引用。
