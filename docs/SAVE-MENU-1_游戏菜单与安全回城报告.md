# SAVE-MENU-1：游戏菜单与安全回城

> 完成日期：2026-07-04  
> 任务状态：100%

## 完成效果

- 手机系统返回键和桌面取消键打开游戏内菜单，不直接关闭应用。
- 菜单包含“继续游戏”“回到角色选择”“保存并退出游戏”。
- 打开菜单时暂停世界、怪物与战斗；继续游戏后恢复。
- 回到角色选择或退出游戏前，立即把人物出生点写为服务端HomeMap对应的比奇城镇并安全存档。
- 应用窗口正常关闭时同样执行安全回城存档。
- Android强杀无法执行退出回调，因此重登逻辑无条件从服务端HomeMap生成角色；即使进程瞬间消失，下次进入也不会出现在野外、洞穴或Boss房。
- 最近活动地图和坐标只作为存档记录，不作为重新登录出生点。
