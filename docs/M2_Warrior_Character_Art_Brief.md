# M2战士人物美术简报

## 定位

- 原创1.76精神续作风格，不复制现有游戏角色贴图、标志性服装细节或逐帧动作。
- 俯视3/4视角的2D手机暗黑刷装游戏角色。
- 战士轮廓优先体现厚重、近战、可靠，缩小到64×96后仍能与法师、道士快速区分。

## 造型

- 成年男性战士，中等偏强壮体型。
- 深蓝灰布甲与暗铁护肩，棕色皮革腰带，少量暗红绑带作为职业识别色。
- 单手宽刃铁剑；无夸张巨剑、无发光神器、无披风遮挡脚底。
- 头部不戴全封闭头盔，便于未来叠加装备外观。
- 颜色避免纯黑吞细节；金属高光控制在像素块级别。

## 八方向锚点

- 顺序：南、西南、西、西北、北、东北、东、东南。
- 所有方向保持同一身高、肩宽、武器长度、配色和脚底位置。
- 脚底锚点固定在64×96帧的`(32,80)`。
- 阴影不画入人物原图，由游戏运行时统一生成。

## 动画交付

- `idle` 4帧、`walk` 8帧、`attack` 6帧、`hit` 3帧、`death` 6帧。
- 攻击关键帧：普通近战第3帧，半月/烈火第4帧，野蛮冲撞第2帧。
- 先生成八方向造型锚点，再基于锚点制作各状态，禁止每个方向独立重设计。

## 禁止项

- 不使用文字、Logo、水印和UI边框。
- 不使用透视夸张、写实软阴影、复杂背景或地面投影。
- 不把武器、人物或衣服裁出画布。
- 不使用纯绿色；生成阶段使用纯绿色抠图背景，后续移除为透明。
