# 4b6ea4e0 → 技能唯一真源 v1.0 差异与迁移清单

## P0：系统阻断项

1. **补齐熟练度闭环**
   - `player_state.gd`新增每技能`rank/current_proficiency`持久化。
   - 只由`SkillCastResult.proficiency_event`触发增长。
   - 每次1–3点，升级需同时满足人物等级与门槛，升级后归零。
2. **只保留一个权威入口**
   - `game_root.gd::_on_player_skill()`改成构造请求，不再结算。
   - 接入`CasterSkillRuntime`或重构为`SkillRuntimeRouter`。
   - 禁止旧入口与新入口同时结算。
3. **消除数据三重覆盖**
   - `skills_source_of_truth_v1.json`为Vanilla唯一成员/进度/MP/机制入口。
   - `profession_growth.json`和`profession_combat_rules.json`只能提供非冲突派生值。
   - 禁止`multiplier_by_level=1.0`覆盖技能等级公式。
4. **把`delay`降级为审计字段**
   - 重命名`legacy_delay`。
   - 新增`body_cast_ms/recovery_ms/total_action_lock_ms/tick_interval_ms/duration`。
5. **候选状态不再默认启用**
   - 只有`historical_verified/source_formula_reference/project_canonical`可进入运行时。
   - `candidate/unverified`不得默认启用。

- 诱惑之光：6秒魅惑 → 驯服/瘫痪/混乱状态机。
- 瞬息移动：前冲220px → 随机传送。
- 圣言术：普通MC伤害 → 不死系一击必杀判定。
- 精神力战法：空施法 → 永久被动准确。
- 集体隐身术：只作用自己 → 目标点3×3友方。
- 群体治疗术：只治疗自己 → 目标点3×3友方。
- 幽灵盾：只自己/同逻辑 → 范围MAC Buff。
- 神圣战甲术：只自己/同逻辑 → 范围AC Buff。
